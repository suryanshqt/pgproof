The documents use these normative terms:

- **MUST / MUST NOT** — required for a trustworthy release
- **SHOULD / SHOULD NOT** — expected unless a recorded design decision explains otherwise
- **MAY** — optional

If documents disagree, product evidence and safety constraints take precedence over implementation convenience. A change to an accepted product boundary requires a short ADR before code changes.
